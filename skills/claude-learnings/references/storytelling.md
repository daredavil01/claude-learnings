# Product and storytelling judgement

The lessons least likely to be written down elsewhere: what a reader actually came
for. Applies to data stories (GB, E20, DQ), interactive pieces (TLWR, ATF, 45D,
MF) and video (RS).

Tags: `storytelling`, `video`

## What to build

1. **Completeness is not a feature.** [45D] Seventy day cards and seventy messages
   (about 70 KB) answered nothing. Build the question the reader came with,
   usually "what is tomorrow?"
2. **Before deriving one control from another, name the question each answers.**
   If you can write two different sentences, keep two controls.
3. **When shortening something periodised, remove whole cycles; if no cut keeps
   the shape, offer none.** [RF]
4. **A cosmetic-sounding edit can be a correctness fix.** Removing one food unit
   fixed two descriptions of the same walker in different units.

## How to show it

5. **When the metaphor can't be completed, change the mapping.** [TLWR] A linear
   lap was 320 million pixels of scroll that nobody travelled; a log scale made it
   a journey.
6. **Put the moment of insight where the reader has committed.** Ask for the guess
   before the explanation, and show the gap in the same picture as the answer.
7. **A signal needs a neutral background.** [TLWR] One shared sky palette made the
   only difference between lanes the one that mattered.
8. **Lead with the concrete.** [GB] A felling order for 32,490 trees with dates is
   more verifiable than megawatts.
9. **Show the edit; don't claim it.** [PW2] Striking out a visitor's own filler
   words convinces in a second where a description convinces nobody.
10. **Give the other side equal weight.** [MF, DQ] The Museum's Reply tab is the
    same size as the charge; DQ presents both radicalisation cases at the same
    weight, as one mechanism.
11. **Same unit is not same measure.** See `data-and-sources.md` §6.

## Video and motion (Reelsmith)

12. **Stills before motion.** Four PNGs take a minute, a render twenty. Review a
    contact sheet per beat, scored 1–10, before rendering.
13. **Screenshot the last frame, not only the first.** [TLWR] Half the rings were
    missing at 40,075 km.
14. **Pin one engine and record why.** Reelsmith pins Remotion and bumps every
    `@remotion/*` package together. See `dependencies.md` §5.
15. **Label illustrative data on screen** ("Example data"). See
    `data-and-sources.md` §9.
16. **Write narration for the ear** — years spelled as spoken, shorter sentences,
    numbers still from the data.
17. **Verify your own playbook's citations.** Reelsmith's verification pass found
    claims attributed to sources that do not contain them; they are now marked as
    house guidance.
